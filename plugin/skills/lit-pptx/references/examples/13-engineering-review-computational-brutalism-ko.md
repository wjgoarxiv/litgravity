## v3 요청 처리 경로

![도 2. v3 요청 처리 경로, 다섯 단계 | 출처: 예시 이미지](assets/example-b.png)

- **1. 수신** TLS 종료와 요청 파싱, 커넥션 풀에서 업스트림 연결 재사용
- **2. 인증** 토큰 검증 캐시 우선, 캐시 미스만 인증 서버 호출
- **3. 라우팅** 경로 규칙 테이블을 메모리에 올려 조회, 규칙 312개
- **4. 전달** 업스트림 호출과 재시도 1회, 서킷 브레이커 임계 5%
- **5. 기록** 구조화 로그와 추적 스팬을 비동기로 내보냄
