# Technique catalog

Index of the technique cards. Pick one or two per divergent round, say which one you are using in a single line before the ideas, and tag every idea with the technique name in brackets, for example `[SCAMPER:combine]`.

| Technique | Card | Pays off when | Output |
| --- | --- | --- | --- |
| Free listing | below | round 1, before any frame bias | raw breadth |
| How might we | techniques-reframe.md | the problem statement is a solution in disguise | 3 to 5 reframings |
| Five whys upward | techniques-reframe.md | the real goal may be larger than the stated one | a broader frame |
| Assumption reversal | techniques-reframe.md | everyone agrees on how the thing works | inverted premises |
| Jobs to be done | techniques-reframe.md | users and motives are unclear | job statements |
| SCAMPER | techniques-generate.md | something exists and can be changed | seven mutation prompts |

## Free listing

Write every answer that comes to mind for the chosen how-might-we, one line each, in no order. The first five are the obvious ones and the target lies past them. An idea that feels small, silly or already known goes on the list too, tagged `[free]`.

## Choosing by what the board shows

| What the board shows | Next technique |
| --- | --- |
| Every idea modifies the current thing | analogy, assumption reversal, constraint flips |
| Every idea is large and risky | SCAMPER:eliminate and SCAMPER:reverse, shrinking constraint flips, crazy eights |
| Ideas read as generic | persona lenses, random stimulus |
| One dimension dominates | morphological box |
| The user is silent or terse | crazy eights, worst-idea inversion |
| Stakeholders disagree | role storming, six hats |
| The frame itself feels off | return to techniques-reframe.md |

## Rotation rule

No technique runs in two consecutive rounds. A Deep session uses at least one technique from each card file.
