# Annotations and callouts

An annotation explains an exception, a boundary or an implication that the primary geometry cannot show alone.

- Write one concise sentence and attach it to the relevant edge or group.
- Add a thin leader line when proximity leaves the target unclear.
- Keep the note outside node text, so the node's name stays unchanged.
- Set it in the diagram's own sans face; serif callout fonts have no role here.
- Mark a threshold, warning or uncertainty with words and shape alongside color.
- Skip speech bubbles, stickers, floating notes and duplicate captions.

The full-editorial variant carries one takeaway line and a compact legend when either helps the reader. A caption that restates the title gets removed.
