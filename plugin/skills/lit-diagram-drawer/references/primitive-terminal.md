# Terminal-window treatment

The terminal treatment is a specialized frame for a command sequence or a code sample. It is a narrow device, and an architecture diagram keeps its ordinary skin.

- Use a flat charcoal frame with a single warm accent.
- The command stays selectable text in the HTML source and live SVG text in the image.
- Prompt, command and result differ by label or indentation, since color alone is insufficient.
- Leave out fake window controls, blinking cursors, status symbols for commands that never ran, and any output that was not provided or verified.
- The frame stays subordinate to the command and its result.

When a system diagram includes a terminal snippet, the diagram uses the ordinary skin and this treatment covers the snippet alone.
