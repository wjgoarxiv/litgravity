# Sketch-derived material

A sketch or whiteboard photo is a source of structure. Its look is optional and arrives only on request.

- Keep the labels, grouping, direction and constraints the user intended.
- Rebuild on a fresh 4px grid using the selected diagram type.
- Hand-drawn jitter, rough marker strokes, source colors and original coordinates stay behind, unless the user asks for a sketch look.
- Ask about empty or ambiguous boxes. Their meaning comes from the user.
- When the import loses information, report what was merged, collapsed or dropped.

A playful hand-drawn finish is an explicit style choice. It stays legible and keeps its contrast, and the texture never softens arrows, text or trust boundaries.
