# Journal-Specific Figure Requirements

## Overview

Each journal sets its own technical requirements for figures. This reference gathers the common requirements of major scientific publishers. **Confirm the current rules in the specific journal's author guidelines before you submit.**

## Nature Portfolio (Nature, Nature Methods, etc.)

### Technical Specifications
- **File formats**:
  - Vector: PDF, EPS, AI (preferred for graphs)
  - Raster: TIFF, PNG (for images)
  - Rejected: PowerPoint, Word, JPEG

- **Resolution**:
  - Line art: 1000-1200 DPI
  - Combination (line art + images): 600 DPI
  - Photographs/microscopy: 300 DPI minimum

- **Color space**: RGB (Nature publishes digital-first)

- **Dimensions**:
  - Single column: 89 mm (3.5 inches)
  - 1.5 column: 120 mm (4.7 inches)
  - Double column: 183 mm (7.2 inches)
  - Maximum height: 247 mm (9.7 inches)

- **Fonts**:
  - Arial or Helvetica (or a similar sans-serif)
  - Minimum 5-7 pt at final size
  - Embed every font in PDF/EPS

### Nature Specific Guidelines
- Panel labels: a, b, c (lowercase, bold) in the top-left corner
- Scale bars on every microscopy image
- Gel images: add molecular weight markers
- Cropping: mark it with line breaks
- Statistics: mark significance and define the symbols in the legend
- Source data: supply it for all graphs

### File Naming
Format: `FirstAuthorLastName_FigureNumber.ext`
Example: `Smith_Fig1.pdf`

## Science (AAAS)

### Technical Specifications
- **File formats**:
  - Vector: EPS, PDF (preferred)
  - Raster: TIFF
  - Also accepted: AI, PSD (Photoshop)

- **Resolution**:
  - Line art: 1000 DPI minimum
  - Photographs: 300 DPI minimum
  - Combination: 600 DPI minimum

- **Color space**: RGB

- **Dimensions**:
  - Single column: 5.5 cm (2.17 inches)
  - 1.5 column: 12 cm (4.72 inches)
  - Full width: 17.5 cm (6.89 inches)
  - Maximum height: 23.3 cm (9.17 inches)

- **Fonts**:
  - Helvetica (or Arial)
  - 6-8 pt minimum at final size
  - Same font across all figures

### Science Specific Guidelines
- Panel labels: (A), (B), (C) in parentheses
- Keep text inside figures short, with details in the caption
- Strong contrast for web and print
- Error bars required, defined in the caption
- Trim excess whitespace

### File Naming
Format: `Manuscript#_Fig#.ext`
Example: `abn1234_Fig1.eps`

## Cell Press (Cell, Neuron, Molecular Cell, etc.)

### Technical Specifications
- **File formats**:
  - Vector: PDF, EPS (preferred for graphs/diagrams)
  - Raster: TIFF (for photographs)

- **Resolution**:
  - Line art: 1000 DPI
  - Photographs: 300 DPI
  - Combination: 600 DPI

- **Color space**: RGB

- **Dimensions**:
  - Single column: 85 mm (3.35 inches)
  - Double column: 178 mm (7.01 inches)
  - Maximum height: 230 mm (9.06 inches)

- **Fonts**:
  - Arial or Helvetica exclusively
  - 8-12 pt for axis labels
  - 6-8 pt for tick labels

### Cell Press Specific Guidelines
- Panel labels: (A), (B), (C) or A, B, C in the top-left
- Related panels match in size
- Scale bars mandatory for microscopy
- Western blots: add molecular weight markers
- Arrows/arrowheads: 2 pt minimum width
- Line widths: 1-2 pt for data

## PLOS (Public Library of Science)

### Technical Specifications
- **File formats**:
  - Vector: EPS, PDF (preferred)
  - Raster: TIFF, PNG
  - TIFF with LZW compression is acceptable

- **Resolution**:
  - Minimum 300 DPI at final size (all figure types)
  - 600 DPI preferred for line art

- **Color space**: RGB

- **Dimensions**:
  - Single column: 8.3 cm (3.27 inches)
  - 1.5 column: 11.4 cm (4.49 inches)
  - Double column: 17.3 cm (6.81 inches)
  - Maximum height: 23.3 cm (9.17 inches)

- **Fonts**:
  - Sans-serif preferred (Arial, Helvetica)
  - 8-12 pt for labels at final size

### PLOS Specific Guidelines
- Figures read clearly without the caption
- Use color when it adds information
- Every figure converts cleanly to grayscale
- Panel labels are optional and recommended
- Open access: figures carry a CC-BY license
- Source data files are encouraged

## ACS (American Chemical Society)

### Technical Specifications
- **File formats**:
  - Preferred: TIFF, PDF, EPS
  - Application files: AI, CDX (ChemDraw), CDL
  - Acceptable: PNG (unsuitable for final publication)

- **Resolution**:
  - Minimum 300 DPI at final size
  - 600 DPI for line art and chemical structures
  - 1200 DPI for detailed structures

- **Color space**: RGB or CMYK (confirm per journal)

- **Dimensions**:
  - Single column: 3.25 inches (8.25 cm)
  - Double column: 7 inches (17.78 cm)

- **Fonts**:
  - Embedded fonts required
  - Sizing consistent across figures

### ACS Specific Guidelines
- Chemical structures: draw them in ChemDraw or an equivalent
- Atom labels: 10-12 pt
- Bond thickness: 2 pt
- Panel labels: lowercase bold (a, b, c)
- Strong contrast required (many ACS journals print in grayscale)

## Elsevier Journals (varies by journal)

### Technical Specifications
- **File formats**:
  - Vector: EPS, PDF
  - Raster: TIFF, JPEG (photographs only)

- **Resolution**:
  - Line art: 1000 DPI minimum
  - Photographs: 300 DPI minimum
  - Combination: 600 DPI minimum

- **Color space**: RGB (for online); CMYK (for print journals)

- **Dimensions**: vary by journal
  - Common single column: 90 mm
  - Common double column: 190 mm

- **Fonts**:
  - Preferred: Arial, Times, Symbol
  - Minimum 6 pt at final size

### Elsevier Specific Guidelines
- Consult each journal's own guidelines (they vary widely)
- Some journals charge for color in print
- Panel labels usually (A), (B), (C) or A, B, C
- A graphical abstract is often required, supplied separately from the figures

## IEEE (Engineering/Computer Science)

### Technical Specifications
- **File formats**:
  - Vector: PDF, EPS (preferred)
  - Raster: TIFF, PNG

- **Resolution**:
  - Photographs/graphics: 300 DPI minimum at final size
  - Line art: 600 DPI minimum

- **Color space**: RGB (online); CMYK (print)

- **Dimensions**:
  - Single column: 3.5 inches (8.9 cm)
  - Double column: 7.16 inches (18.2 cm)

- **Fonts**:
  - Sans-serif preferred
  - Minimum 8-10 pt at final size

### IEEE Specific Guidelines
- Figures stay readable in black and white
- Color figures are free of charge in online publication
- Panel labels: (a), (b), (c) in lowercase
- Captions sit below the figures, on the same page
- Run the IEEE graphics checker tool before submission

## BMC (BioMed Central) - Open Access

### Technical Specifications
- **File formats**:
  - Any standard format is accepted
  - Preferred: TIFF, PDF, EPS, PNG

- **Resolution**:
  - Minimum 600 DPI for line art
  - Minimum 300 DPI for photographs

- **Color space**: RGB

- **Dimensions**:
  - Flexible, with readability in mind
  - Maximum width typically 140 mm

- **Fonts**:
  - Embedded and readable

### BMC Specific Guidelines
- Open access: CC-BY license required
- Upload figure files separately
- Panel labels follow the conventions of the field
- Source data is encouraged
- Accessibility matters (colorblind-friendly)

## Common Requirements Across Journals

### Universal Best Practices
1. **Choose vector or lossless formats for graphs/plots**: JPEG compression leaves artifacts
2. **Embed all fonts**: in PDF/EPS files
3. **Layer structure**: flatten images (merge layers in Photoshop)
4. **RGB vs CMYK**: most journals now take RGB (digital-first)
5. **High resolution**: start high and reduce when needed
6. **Consistency**: one style across all figures in the manuscript
7. **File size**: balance quality against reasonable file sizes (typically <10 MB per figure)

### Submitting Figures
- **Initial submission**: lower resolution is often acceptable (for review)
- **Revision/acceptance**: high resolution is required
- **Separate files**: one file per figure
- **File naming**: clear, systematic names
- **Supporting information**: its requirements may differ

## Checking Requirements

### Before Submission Checklist
1. Read the figure section of the journal's author guidelines
2. Check file format requirements
3. Verify resolution requirements
4. Confirm size specifications (width × height)
5. Check font requirements
6. Verify color space (RGB vs CMYK)
7. Check panel labeling style
8. Review supplementary materials requirements
9. Confirm file naming conventions
10. Check file size limits

### Useful Tools
- **ImageJ/Fiji**: inspect and adjust DPI
- **Adobe Acrobat**: verify embedded fonts and check PDF properties
- **GIMP**: a free alternative to Photoshop for raster editing
- **Inkscape**: a free vector graphics editor

## Resources

- **Journal websites**: open the "Author Guidelines" or "Instructions for Authors" page
- **Publisher resources**: many publishers provide templates and tools
- **Format conversion**: pick reputable tools and inspect the output quality
- **Help desks**: contact journal staff when a rule is unclear

## Notes

- Requirements change periodically, so verify the current guidelines each time
- Preprint servers (bioRxiv, arXiv) often have different requirements
- Conference proceedings may have separate requirements
- Some journals offer figure preparation services (often paid)
- Supplementary figures may have relaxed requirements compared to main text figures
