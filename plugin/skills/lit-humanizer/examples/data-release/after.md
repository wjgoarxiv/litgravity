# Bicycle counts, 2025 release

The city traffic office collected these counts with automatic counters at 14 stations on all 365 days of 2025, from 1 January to 31 December. The file has 5,110 daily rows, one per station and day, with the stations in alphabetical order.

Harbour Road was offline for 9 days and Mill Lane for 23. Those days are blank: a blank means the counter was off, and a zero means it counted no bicycles.

Each row has five columns: station, date, count, weather code and a public-holiday flag. The weather code comes from the regional weather service and uses its four categories: dry, light rain, heavy rain and snow.

In heavy rain the counters miss some riders. The traffic office puts the undercount at 3 to 5 percent on those days.
