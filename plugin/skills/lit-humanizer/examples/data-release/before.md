# Bicycle counts, 2025 release

Source: city traffic office, automatic counters.

The dataset covers 14 counting stations and 365 days, from 1 January to 31 December 2025, for a total of 5,110 daily rows. Two stations, Harbour Road and Mill Lane, were offline for 9 and 23 days respectively; those days are left blank rather than recorded as zero.

The file lists the stations in alphabetical order. These figures are not intended as a ranking of the stations.

Each row has five columns: station, date, count, weather code and a flag for public holidays. The weather code comes from the regional weather service and uses its four categories (dry, light rain, heavy rain, snow).

Counters miss some riders in heavy rain. The traffic office estimates the undercount at 3 to 5 percent on such days.
