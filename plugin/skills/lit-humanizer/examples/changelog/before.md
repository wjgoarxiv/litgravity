# Changelog

## 3.2.0 (2026-08-12)

This groundbreaking release stands as a testament to our relentless focus on readers.

- Added: offline mode for the reading list, which stores up to 200 articles on the device.
- Changed: the default font size is now 17 px instead of 16 px.
- Fixed: articles with right-to-left text no longer break the layout.
- Removed: support for Android 8.

Without further ado, update today and enjoy a seamless reading experience!
