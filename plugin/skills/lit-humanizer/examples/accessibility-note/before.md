Certainly! Here is the accessibility note for the volunteer sign-up form.

The sign-up form has been reviewed for accessibility. It is worth noting that every field now has a visible label, and screen readers announce each error message aloud. Moreover, the submit button can be reached with the keyboard alone. Additionally, the contrast of the hint text was raised from 3.2:1 to 4.8:1, which stands as a testament to our commitment to inclusion.

One issue remains: the date picker cannot be operated with the arrow keys. Users can type the date in the format DD/MM/YYYY instead. A fix is planned for the 14 November release.

**Verification status:** the note was tested with two screen readers on desktop and one on a phone. Testing with switch devices has not been carried out yet.

I hope this helps!
