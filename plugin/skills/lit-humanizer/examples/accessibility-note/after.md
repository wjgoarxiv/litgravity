# Accessibility note: volunteer sign-up form

Every field on the form has a visible label, and screen readers announce each error message aloud. The submit button can be reached with the keyboard alone. The contrast of the hint text rose from 3.2:1 to 4.8:1.

These results come from tests with two screen readers on desktop and one on a phone. Switch devices have not been tested yet.

The date picker still ignores the arrow keys. Users can type the date as DD/MM/YYYY instead. The fix is planned for the 14 November release.
